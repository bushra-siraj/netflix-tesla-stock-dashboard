# Netflix vs. Tesla Stock Performance Dashboard

An interactive web application built with **Streamlit** and **Plotly** to visualize and compare the historical stock performance of Netflix (NFLX) and Tesla (TSLA).



## 📊 Project Overview

This dashboard allows financial analysts and investors to quickly compare the price trends of two major technology companies. It features interactive line charts, key performance metrics displayed in flip cards, and detailed data insights.

## 🛠️ Features

| Feature | Description |
| :--- | :--- |
| **Interactive Line Chart** | Visualize closing prices over time with zoom and hover capabilities using Plotly. |
| **Metric Flip Cards** | View the latest price and daily change on the front; hover to flip and see High/Low/Volume stats on the back. |
| **Date Range Filter** | Select specific timeframes to analyze trends during specific market periods. |
| **Data Download** | Option to view and download the merged raw data used in the analysis. |

## 📂 File Structure

| File/Folder | Description |
| :--- | :--- |
| `app.py` | Main Streamlit application script |
| `NFLX.csv` | Historical stock data for Netflix |
| `TSLA.csv` | Historical stock data for Tesla |
| `README.md` | Project documentation |
| `.streamlit/` | Configuration directory |
